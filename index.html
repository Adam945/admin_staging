Aktivasi Ujian & Token

Status ujian yang tersedia saat ini adalah Draft, Terbit, dan Tutup. Token ujian khusus untuk proktor belum diimplementasikan dan tidak boleh dianggap aktif.

Catatan operasional

Terbitkan hanya setelah soal dan jadwal diperiksa. Fitur token proktor, aktivasi per ruang, dan kunci otomatis berdasarkan sesi memerlukan dukungan backend terlebih dahulu.

Backup & Arsip

Panel ini adalah panduan arsip; belum menjalankan backup database otomatis.

  1. Ekspor laporan hasil ujian melalui menu Laporan Nilai.
  2. Simpan salinan file HTML dashboard dan kode Edge Functions sebelum perubahan.
  3. Gunakan fitur backup resmi Supabase untuk mencadangkan database; jangan menyimpan service-role key dalam file arsip HTML.
  4. Catat tanggal backup, ujian yang dicakup, dan lokasi penyimpanan yang memiliki akses terbatas.
  5. Uji pemulihan di lingkungan staging sebelum mengandalkan backup.
